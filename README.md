# 진해신항초등학교 급식 알리미 (PWA)

나이스(NEIS) 교육정보 개방 포털 API를 활용한 **진해신항초등학교**(`S10` / `9022445`) 전용 급식 식단 PWA 앱입니다.

## GitHub Pages 배포 방법
1. GitHub에서 새 저장소(Repository)를 생성합니다. (예: `shinhang-meal`)
2. 압축을 푼 모든 파일(`index.html`, `manifest.json`, `sw.js`, `icons/`, `README.md`)을 저장소 최상위(root)에 업로드합니다.
3. 저장소의 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 설정하고 **Save**를 누릅니다.
4. 약 1~2분 후 생성되는 `https://<아이디>.github.io/<저장소명>/` 주소를 학생·학부모에게 공유합니다.

## 스마트폰 앱처럼 설치하기
- **안드로이드 (Chrome / 삼성 인터넷)**: 링크 접속 후 상단 **'앱 설치'** 버튼 또는 브라우저 메뉴 → **'홈 화면에 추가'**
- **아이폰 (Safari)**: 링크 접속 후 하단 **공유(□↑)** → **'홈 화면에 추가'**
